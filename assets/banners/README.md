# Bannières de titre

Un bandeau ouvragé posé **derrière** le titre d'une page, à la place du
titre nu sur du vide. Quatre pages en attendent une : Magasin,
Les Adversaires, Diagonale de la Puissance, Récompenses.

Le texte reste du texte — il se redimensionne, il se lit par un lecteur
d'écran : **la planche ne porte aucun mot.**

Dossier facultatif : sans image, le titre s'affiche seul, comme
aujourd'hui. Chemins, dimensions et prompts : **`assets/PROMPTS.md`, § 4**.
Câblage : `[ART]` dans `css/style.css` (classe `.art-banner`).
